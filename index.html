CedarTab Privacy Policy

Last updated: 5 October 2026

CedarTab is a Microsoft Edge new-tab extension that displays and organizes bookmarks from a folder chosen by the user. CedarTab does not operate a server, include analytics or advertising, or transmit browsing data to the developer or third parties.

Information CedarTab accesses

  • Bookmarks: CedarTab reads the selected bookmark folder to display links and categories. It creates, renames, or moves bookmarks and folders only after a user performs the corresponding action.
  • Open tabs: If the user chooses “Add from open tabs” and grants the optional tabs permission, CedarTab displays eligible open tabs for selection. Only tabs selected for Focus are retained.
  • Recently closed sessions: If the user opens Recently closed and grants the optional sessions permission, CedarTab asks Edge for recent tabs or windows so the user can restore them. CedarTab does not retain this list.
  • Favicons: CedarTab uses Edge's browser-provided favicon facility to display site icons. These requests are not sent to a CedarTab server.

Storage and synchronization

The selected-folder breadcrumb, appearance setting, and tile-density setting are stored with the browser's synchronized extension storage. Microsoft Edge may synchronize those settings through the user's signed-in browser profile when sync is enabled. Microsoft, not the CedarTab developer, operates that synchronization service.

Focus links and the device-specific bookmark-folder identifier are stored locally in the extension's browser storage. Focus links remain on that device unless the user removes them, clears the extension's data, or uninstalls CedarTab.

Collection, sharing, and sale

CedarTab does not collect information on developer-controlled systems. It does not sell, rent, share, profile, or use user information for advertising. It does not use cookies, analytics SDKs, or remotely hosted executable code.

User control and deletion

Users can remove individual Focus links inside CedarTab. Synchronized settings and local extension data can also be removed through Microsoft Edge by clearing extension data or uninstalling CedarTab. Bookmarks remain ordinary Edge favourites and can be managed with Edge's bookmark tools.

Changes to this policy

If CedarTab's data practices change, this policy and the Microsoft Edge Add-ons disclosures will be updated before the changed functionality is released.

Contact

Questions about CedarTab or this policy can be directed to the developer through the publisher's GitHub profile.
